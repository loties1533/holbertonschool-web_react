Ce dépôt regroupe les exercices du curriculum **Web React** de Holberton School, avec un focus sur TypeScript et les bonnes pratiques de typage en React.

## 🚀 Installation

```bash
# Cloner le repo
git clone https://github.com/loties1533/holbertonschool-web_react.git
cd holbertonschool-web_react

# Exemple — TypeScript
cd TypeScript/task_0
npm install
npm run build
```
